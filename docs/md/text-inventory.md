# Text inventory: The Moon Dwellers (BLJS10335)

Phase 3 output, 2026-10-15. Generated by `tools/extract_all.py` and `tools/classify.py`.
The worksheets are in `worksheets/<Archive>/<path>.json`, plus `worksheets/EBOOT.elf.json`.

## Carriers

`textscan.py` found Japanese text in every known carrier and nowhere else that a player sees:

- **Shader source comments** in `General3d/Dat/Map/commonShader.PSSG`.
- **Placeholder names** (プレイヤー) in `Map/UnitToolData/*.utd`.
- **One string** in a demo-battle file, `DemoBtlData/994.ebd`.
- **Image data** (DDS, BN2) that happens to decode as text.

None of these are translated.

- **Unique** counts distinct (format, Japanese) pairs, which is the unit the translation memory works in.
- **In 2nd OG TM** means an exact `FORMAT\tjp` hit in `translations/tm.json`. That English is pre-filled, so it costs nothing and reads the same as our 2nd OG patch.
- **In other TM** means the same Japanese in another format or in Gaiden's `tm_ogg.json`. It is a reference only, not pre-filled.
- **Left for the AI pass: about 37,900 unique strings.** For comparison, 2nd OG translated about 56,000 unique strings for $65.86.

## FIXH field map (re-derived for Moon Dwellers)

`tools/fixh_fields.py` finds record fields whose values are string indices. Changes from 2nd OG, all in `fixh.FIELD_MAP`:

| Table | Change |
|---|---|
| AbilityElementData | desc at 64 (was 54) |
| AceFullTuneBonusData | **new:** name u16 at 2, desc u16 at 424 |
| KeyWordData | indices widened to u16 at 2/4/6/8 (was u8 at 2/3/4/5), because there are now 395 strings |
| PilotData | voice actor at 0x132 (was 0x100) |
| PlayEndMessageData | **new:** key u8 at 2 (internal), title u8 at 3 |
| ProgStrData | **new:** text u16 at 2. Its 75 unreferenced strings (auto-battle settings, stat help) are shown by code, so `ORPHANS_DISPLAYED` translates them. |
| StageData | every field +1: title 3, summary 4, title_b 5, route 6, icon 16 |
| UnitData | height/weight at 0xCC/0xCE (was 0xA8/0xAA) |

`fixh.UNUSED_TABLES` lists the six tables the EBOOT never loads.

## Open points

- **EBOOT:** 1,246 strings, many from debug menus (描画ＯＮ／ＯＦＦ, 背景カラー …). They are translated anyway, because 94% are already in the 2nd OG TM.
  They are replaced in place, so the budget is the original byte length.
- **MTI** names are `terrain@designer note`; only the part before `@` is shown.
- **LOGO pool-B labels** (151) stay Japanese until the phase 4 render test shows whether any are displayed.
